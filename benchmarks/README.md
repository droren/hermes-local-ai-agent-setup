# Local model benchmarks

Model selection should be based on the actual local workload.

Suggested benchmark dimensions:

- task success rate;
- review defect detection;
- test quality;
- structured output validity;
- tool-call reliability;
- tokens/sec;
- peak memory;
- concurrent-agent throughput;
- operator correction rate.

Store benchmark results separately from model definitions so the same capabilities can be remapped as better models appear.
